# `art/` — original assets

Every asset here is original work, made for this project. Freelingo ships nothing it did
not make. Sources live here (SVG, pose sheets, sound sources); built sprite sheets and the
baked sound bank are produced by the art pipeline.

What v1 needs (plan §Art and sound — a P3 entry criterion):

- five parrot poses at 64 px and 240 px, plus a phoenix pose set (S075)
- a 3-4 character cast with speech-bubble avatars (S034)
- two tableau sprite kinds (S020)
- chest / book / trophy / speaking / alphabet node art
- story covers in `{gilded, active, locked}`
- 13 achievements x tiers, with no holes
- a cosmetics catalogue (the gem sink)
- nine widget states x three sizes, and the share-card composition
- a sound bank: stings, fanfare, a shimmer bus at -6 dB, earcons

No `.riv` files enter this repository until the Rive editor terms are cleared
(EC-PLAT-09); v1 uses code poses.
