# P2 round 6 — authored-first Spanish (founder ruling B21, 2026-09-16)

Base: **`r6/main`** = `codex/p3-app` (Codex's integrated P3–P8 candidate, 150 commits) with `main` merged in. Draft PR #1 (`r6/main` → `main`) exists so that `ci.yml`, `native-e2e.yml` and `pack-ci.yml` run on every push to `r6/main`. **Nothing in this round touches `main`.** The gate is proven on the PR's CI runs.

## Why this round exists

Five attempts at a corpus-first Spanish pack ended red. Round-5 attempt 1 (commit `fca9a57`, pack CI run 34734954606): G0–G9 built, then `validate es` failed with 11/17 checks green, 6,517 blocking findings and 316 warnings; the exact-fingerprint 300-item review scored **101 wrong / 17 awkward / 182 OK (33.67 % wrong, PROVISIONAL)**. Round 4 had measured 4.00 %. Repair rounds fixed named patterns without moving the rate. `docs/P2-TAKEOVER.md` has the full record, including five reproduced adversarial findings in G7 (subject-drop proof, listening shapes accepting pro-drop, gloss token indices vs punctuation, authored slots losing source identity, caller-level cloze guards).

## The ruling (verbatim from `docs/P2-BLOCKERS.md`, 2026-09-16)

Every shipped Spanish item is **authored** by agents against the unit brief, in the existing `content/es/candidates/` shard format, at the unchanged **20-per-slot floor**. The corpus becomes **attestation only** (naturalness score, optional witness); it is **never required to fill a slot**. Corpus sentences may still ship where they pass every validator unchanged. Unchanged: all validators, the 300-item sample, the 2 % gate, the verbatim `PROVISIONAL (unreviewed by a paid native speaker)` label, per-item provenance (authored items show `authored` with method and rubric hash to the learner), S152 credits, stable ids, every invariant. The red-twice stop condition restarts at zero for this round.

## Lanes this round needs (the planner turns these into tasks with disjoint file globs)

1. **Contract / deps task — runs first and alone.** (a) `CONTENT_SOURCE_POLICY = "authored-first"` (named, dated) in config: G5 fills **every** slot from candidate shards; G4's corpus selection becomes an optional **witness** carried on the slot, never the shipped sentence unless no accepted authored candidate exists AND the policy allows it (it does not, by default); G6 never rejects for a missing witness; the attestation score is recorded, not gating. (b) `coursekit gaps es --all-slots` → `content/es/authoring/full-brief.jsonl` (header names the build, digest over all 1,584 slots; same per-slot fields as today plus `already_authored: <n>` and `corpus_witness: <text|null>`). (c) **Re-shard** existing candidates by unit into `content/es/candidates/u<NN>.jsonl` (one file per unit, `u01.jsonl … u30.jsonl`), preserving every row byte-for-byte except file membership, with a test proving the multiset of `(slot, text)` is unchanged; delete the old shards. (d) **One ship-order rule**: the first accepted candidate in sorted read order ships in G5 *and* is the one G7 expands; falsifier test. (e) `coursekit check-candidates <file>`: schema, `ledger_digest` against the current build's ledger, closed vocabulary (`allowed_lemmas` of the slot), token window, duplicate `(slot, text)` across all shards, back-translation score ≥ 3, count per slot; exit 0/1 with a per-row report. (f) Provenance contract for G9/manifest/S001: authored items render `authored` + `authoring_method` + `rubric_hash` (sha256 of `gapfill-rubric.md`); corpus witnesses keep licence/attribution rows. (g) `uv sync --locked` in `~/freelingo-wt/r6-main/tools/coursekit` so authoring lanes can run the checker from that one venv. No new dependency is expected; if one is truly needed this task owns `pyproject.toml` + `uv.lock`.
2. **Authoring lanes — one per unit (30), or two per unit split by lesson range when a unit has more than 60 slots; each owns exactly its unit file(s).** For every slot in its units: keep existing rows that pass the review rubric, **replace** rows that would be scored wrong or awkward (a replacement is a new row; never edit `text` in place — INV-PACK-10), and author new rows until each slot holds ≥ 20 accepted candidates. Rows are situated, natural, learner-facing sentences a Duolingo A1 unit would actually teach (the unit's `function` and `grammar_concept` are the point of the sentence, not decoration), closed vocabulary, `ledger_digest` copied from the full brief, `backtranslation.score ≥ 3` judged honestly, `provenance: "llm"` (the internal enum; the contract decides whether it is renamed), `author: "claude-opus-5 (agent; Freelingo r6-u<NN> lane)"`, `generated_at: <date>`. Avoid the shapes the reviewers marked: semantically empty but grammatical sentences, wrong sense of a polysemous word, reflexive-as-emphatic, `nuevo` for fresh bread, glosses that mislead, register drift (`usted` outside u23), pro-drop where the shape must keep the subject. Run `check-candidates` on the file until it exits 0.
3. **Pipeline lanes (parallel with authoring):** G7 quality (takeover findings 1–5 with falsifiers; consider adopting `codex/p2r5-g7`); G6 attestation + upstream validation (consider `codex/p2r5-upstream`); sampling/manifest/provenance + validators for the authored-first population (consider `codex/p2r5-sample`); signing/loader proof in CI if anything is still missing after `95b50c2`. Each lane owns disjoint modules and their tests.
4. **Integration** on `r6/main` (worktree `~/freelingo-wt/r6-main`): merge one branch at a time with rebase-and-retest (`pnpm lint && pnpm typecheck && pnpm test && pnpm test:coverage-map`; `uv run pytest` with the live SimAlign measurement deselected; `coursekit check-candidates` over every shard), run `uv run coursekit build es` end to end in the background, push, watch PR #1's CI, download the pack artefact, prove `packages/core` loads it, draw the 300-item sample with the round's seed.
5. **Independent review** of the 300-item draw against `RUBRIC.md` by a reviewer agent that authored none of the rows, writing `content/es/review/scores.jsonl` + a dated `scores-method.md`; the old scores move to `history/`. The measured rate is published with the PROVISIONAL string whatever it is.
