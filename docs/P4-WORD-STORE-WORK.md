# Permanent word history — implementation checkpoint, 2026-09-13

`SqliteWordStore` consumes reviewed runtime lexical declarations and exact persisted display receipts. Loading a source does not introduce it. The content-hash semantic word identity is shared across courses; countable words enter the account union once, while particles, bound morphemes and characters add neither scalar. Course removal preserves the account history and earned vocabulary awards. Course-visible Words and Score projections must separately exclude quarantined current-course rows; the account union is not that projection.

A caller must supply the actual new-database creation fact to initialize empty known history. Migration and restore never turn legacy scalar counters into invented vocabulary evidence. Native initialization and the actual display callback are not connected in this checkpoint.

Completion prepares an opaque plan after the actual scheduler write, using the scheduler state loaded before review, all ordered answer targets, source checkpoints, receipts and final saved FSRS cards. The same owning store applies it only after the global committed session and course link exist inside the caller's exclusive transaction. The reward helper will retain this private store and plan; callers cannot provide derived counters or substitute a different plan. FSRS is not replayed to manufacture history.

The named Freelingo implementation policy uses the scheduler's 21-day stability threshold and two consecutive qualifying scheduled successes. This numerical rule is not presented as a measured Duolingo constant. Early successes do not advance the streak; wrong targets reset it. Each physical parent answer can contribute at most one qualifying review per semantic word. A wrong MATCH target does not erase successful targets for other words, and a later wrong target for the same word prevents qualification for that parent. The first earned claim is permanent. Review evidence preserves actual Date instants and compact source identities rather than serializing grading dictionaries.

The reader validates the permanent introduction, ordered review history, first qualifying claim and cached counters together. Malformed cards, contradictory source/receipt identities, fabricated claims, stale plans and incomplete target populations fail instead of becoming trusted vocabulary counts.
